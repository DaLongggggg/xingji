# 地图海岸线数据

## `ne10m-land-china.rings.json`

- 来源：[Natural Earth — 1:10m Land](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)，更新时间 2022-05-09，公开领域。
- 内容：由 `ne_10m_land.shp` 陆地多边形裁切至 70–140°E、15–55°N，使用 WGS84 经纬度坐标，保留五位小数，共 754 个环。
- 用途：地图海陆轮廓与底图显示，不作为行政边界或笔记归属数据。
- 精度：比例尺为 1:10,000,000，并非 10 米地面分辨率；无法表达街道级海岸线，港澳等小区域可能缺少细节。
